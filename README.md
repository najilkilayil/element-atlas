# Element Atlas - Virtual Periodic Table

Element Atlas is a virtual periodic table using HTML, CSS and JavaScript. It is very useful to understand, learn and observe how the periodic table works and aligned. Try to open in desktop site since it is not responsive.


The elements are aligned using JavaScipt Array concept. Which is very easy and helpful to look over and edit!

## Periodic Table Layout

| Period | Element Number |
|:------:| :--------------: |
| 1      |  1 - 2  |
| 2      |  3 - 10 |
| 3      |  11 - 18 |
| 4      |  19 - 36 |
| 5      | 37 - 54  |
| 6      | 55 - 86  |
| Special Case 6 | 57 - 71 |
| 7      | 87 - 118 |
| Special Case 7 | 89 - 103 |

In this website's layout *Lanthanides* (Special case of 6) elements are placed in the 8th row.

And *Actinides* (Special case of 7) elements are placed in the 9th row.

## Techinical Side
The owner placed all the elements data inside an JS array with values number of the element, syumbol of the element, group and period number of the elemen. Then each element will create each sections width row as the period number and column as the group number.
